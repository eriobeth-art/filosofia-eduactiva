## Publicación en GitHub Pages
1. Crea un repositorio, por ejemplo `filosofia-educacion`.
2. Sube `index.html`, `.nojekyll` y este `README.md` a la raíz.
3. Ve a **Settings → Pages**.
4. Selecciona **Deploy from a branch**.
5. Elige **main** y **/(root)**.
6. Guarda y espera a que GitHub publique el sitio.

## Dominio personalizado
Si deseas vincular un subdominio de `edupsic.com`, agrega el dominio en **Settings → Pages → Custom domain** y crea el CNAME correspondiente en tu proveedor DNS. No se incluye un archivo `CNAME` en este paquete para evitar fijar un subdominio sin confirmación.
